Notes du prototype
  • Tous les calculs se font dans votre navigateur, dans un thread séparé.
  • L'aperçu et l'export utilisent les mêmes coordonnées : seule la finesse change.
  • Les images importées sont lues en 8 bits par le navigateur, même un PNG 16 bits.
  • Seules les couches modifiées (et celles au-dessus) sont recalculées pendant les réglages.
